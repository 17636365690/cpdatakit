# v0.11.0 release verification

The release adds one bounded feature: saving and loading confirmed CSV import settings with a
fresh-file difference preview. It retains the existing import, normalization, schema and mapping
paths. File-specific descriptions and hashes are not transferred through reusable settings.

The implementation and independently reviewed local evidence are documented in the
[development snapshot](2026-10-07-repeat-import.md). That snapshot intentionally retains its
prepublication status and development-wheel hash; it is not a receipt for the v0.11.0 distribution.

## Behavioral evidence

- The echemdb purple and brown source files contain 3,501 and 5,001 records. Original CSV,
  CPDataKit HDF5 and saved/reopened native unitpackage Entry values match exactly. The second
  file retains its own KBr metadata and hash, without copying the first file's KI conditions or
  its reference-electrode offset description. SCE potential scale and actual Pt-Pseudo electrode
  remain distinct.
- Two PyIRoGlass spectra contain 3,942 records each, with a 9-record composition/thickness table.
  Exact sample IDs, units, row/column order and independent hashes are preserved. Missing IDs
  are rejected by the case handoff check; duplicate IDs are rejected by that check and the
  existing index/unique schema constraints.
- Browser acceptance exercises saving settings, reload, second-file reuse, empty new source
  descriptions, E/I reorder detection, stored `coordinate` roles, export downloads and refresh.
  Actual downloads pass 43 independent checks, including exact numeric readback and an actual
  HDF5-to-Entry handoff. A separate installed-wheel environment verifies both real cases.
- TDD regressions cover changed and legacy settings, malformed inputs, altered saved bundles,
  consistent-byte export, stale asynchronous loading and preserving per-file confirmation.

The final local feature suite recorded 1,857 passed, 1 skipped and 40 warnings on Windows with
Python 3.12.13. Versioned release metadata, package builds, fresh installation and the repository's
required CI checks are rechecked during publication. Remote CI results belong to their exact
commit; use the release/tag checks rather than treating earlier development results as remote CI.

## Scope and provenance

The [case guide](../../examples/repeated-import/README.md) pins upstream commits and license
sources. Third-party raw archives, GPL reader source, local environments and machine-specific
evidence are kept outside the product repository and distributions.

CSV/HDF5 comparisons are exact. Native spectrum parsing uses a predeclared rtol=1e-14 and
atol=1e-12; the tested source spectra also matched exactly. Native unitpackage comparisons used
predeclared rtol=1e-12 and atol=1e-15 and also matched exactly. Browser textarea CRLF/LF differences
are normalized only for text comparison, with full YAML semantics independently checked.

The complete PyIRoGlass installation is not validated: its NumPy constraint conflicts with
CPDataKit and its mc3 dependency failed to compile on the tested Windows host. The case executes
the unchanged pinned SampleDataLoader class and required original imports, retaining source and
AST hashes. It does not execute MCMC or claim full native-package availability.

These checks establish the tested engineering behavior. Headerless/indistinguishable columns,
units not written in CSV, experiment facts and sample associations still require source review.
No net convenience advantage over the mature native workflows, human time savings, calibration,
physical validity or experimental generalization has been established.

## Publication identity

The version is synchronized across package metadata, runtime version, citation, current install
instructions, changelog and release notes. The existing protected PR process and tag-triggered
Trusted Publishing workflow are used without dependency or governance changes. A successful
tag/build alone is not PyPI publication; final acceptance checks both registries' artifact hashes
and a fresh installation from the public PyPI index.
