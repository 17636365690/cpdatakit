# v0.10.2 report provenance repair verification

Prepared 2026-10-06 from main `dbefb3d87631183bf2d9e5af57d7fc481324e258`.
The change is limited to output sanitisation, regression tests and release documentation.

## Regression evidence

The initial regression cases failed before the implementation changed: 23 failed and one passed.
Independent review identified four additional failing cases for adjacent Windows/UNC paths,
chained unit quotients and paths preceding public references. That implementation candidate passed
76 focused tests, followed by 1,817 tests with one skip and 40 warnings on
Windows / Python 3.12, with 90.44% coverage against the existing 85% gate. Ruff and formatting
checks passed. Release review subsequently added five failing cases for unkeyed URL query/fragment
content and one ordinary-anchor control. The additional boundary was repaired, and the focused
tests plus release-metadata checks passed all 104 cases. The exact versioned release is also
subject to the release PR's full CI checks; the 1,817-test figure describes the earlier candidate.

Tests check public references and scientific unit expressions as well as private-path and
credential removal, rather than accepting an entirely redacted result as success. They cover
HTML, JSON and Markdown output, repeated sanitisation, and the HDF5-to-report path.

## Real external workflow

The source was the author-supplied `schonig_2023_entropic_5948_f1_purple.csv` and companion YAML in
[echemdb/electrochemistry-data](https://github.com/echemdb/electrochemistry-data/tree/04ceb25622008e5b823a665759fcbce9bc3f4f7f/literature/source_data/schonig_2023_entropic_5948).
The data license was CC BY 4.0; authors: Marco Schönig and Rolf Schuster, *Entropic contributions
to the stability of electrochemically adsorbed anion layers on Au(111): a microcalorimetric study*,
PCCP 25, 5948–5954 (2023), DOI [10.1039/D2CP04680F](https://doi.org/10.1039/D2CP04680F).
No experimental payload is added to this repository by the repair.

The local task used the existing CSV confirmation interface to preserve the 3,501 rows in their
original `t,E,I` order, with units `s,V,A`. The complete source metadata was manually retained in
the source-description text. A native unitpackage Entry read-back verified exact numeric equality.
This is an explicit external handoff, not automatic YAML integration.

Using an independently installed repair wheel, the unchanged HDF5 generated HTML, JSON and
Markdown reports with the DOI and `mol / l` / `mV / s` expressions intact. The report's stored YAML
semantics matched the original. The SCE potential scale and actual Pt-Pseudo reference electrode
with its source-declared offset remained distinct. The browser upload/report/download workflow
also passed; its downloaded HTML matched the directly generated report byte-for-byte. Original
data and the earlier failing reports were preserved.

## Scope

These checks establish numeric and report interoperability for one supplied curve, not physical
validation, a complete paper reproduction or measured human time savings. Existing conservative
handling of unquoted path-adjacent prose remains; HDF5 internal group labels such as `/data` are
still subject to the prior path-redaction policy. No public API, file schema, runtime dependency,
publishing workflow or protection setting changes in this release.
Unit protection recognises quotients of unit atoms, including chained division and powers;
arbitrary parenthesised expressions such as `J / (mol K)` remain outside this repair.

Hosted matrix, release artifacts and registry installation are verified separately by the release
PR and tag workflow; the local counts above are not presented as remote CI results.
