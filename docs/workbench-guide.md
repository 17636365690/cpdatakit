# 中文工作台与数据报告

本页描述 v0.10.1 工作台，包含 CSV 确认导入和结果继续处理。
可安装软件包或当前源码；Python 要求为 3.12 或更高版本：

```powershell
python -m pip install -e .
cpdatakit ui --workspace ./cpdatakit-workspace
```

启动后创建或打开一个项目。文件、规则、任务记录和结果保存在所选本地工作区。
服务仅绑定本机回环地址；浏览器静态资源随安装包提供，使用时不需要联网。
第一次使用可从[三行 CSV 完整示例](../examples/csv-intake/README.md)开始，包含独立环境安装、
实际列声明、期望换算结果和错误修正。工作台无需安装 Node.js。

## 1. 准备数据与规则

### 仪器导出的 CSV、TSV 和文本表格

打开“CSV 导入 · 预览并确认字段”，选择原始文件，设置分隔符、表头行、独立单位行、
小数符号和编码，然后点击“预览表格”。行号从 1 开始，包含空行；表头或独立单位行
填 0 表示没有该行。支持逗号、分号和制表符，编码为 UTF-8（含 BOM）或 GB18030。
默认最多 64 MiB、100,000 条数据，每列显示前五个原始样本值。

例如表头为 `(sec);(mm);(N);;(MPa);(mm/mm)` 的拉伸导出文件，选择分号后应看到六列。
按来源记录确认时间、位移、力及应力应变字段。无名称、无单位的第四列保持未确认，
可显式取消保留；原列继续保存在原文件和导入清单中。应力和应变的定义不能仅凭单位推断。

逐列填写输出字段名、类型、来源单位、输出单位和用途。单位建议必须对照来源确认；
例如力的来源单位填 `N`，输出填 `kN`。整数若需要换算成小数，请明确选择小数类型。
字段名使用平铺名称，不能包含 `/`；未知数字单位须先核对来源，不能以无量纲代替。
数据定义与来源说明中记录本次采用的约定，再勾选确认并点击“确认并导入”。

导入会保存原始字节、已确认 HDF5、独立规则和清单，并选中这份数据及其规则。
可以直接生成报告，也可下载原文件、正式规则和导入清单。缺失、行宽异常、数值精度
无法保证时会指出问题并停止，不会删除异常行来取得通过结果。
错误中的 `CSV row` / `column` 指原文件行号/列号；页面同时显示中文修正提示。
若文件或解析设置改变，请重新预览。文字类型不会使用数字单位。

### 已准备好的数据与规则

在“数据规则（Schema）”中选择本次数据使用的规则。规则声明字段名称、类型、单位和维度。
表格可使用内置曲线、采样点、二维场规则，也可展开“添加自定义规则”上传自己的 JSON。
多维数据使用 schema 2.0。

v0.9.1 在规则上传失败时返回固定错误提示，避免把内部异常细节显示给浏览器。
请核对 JSON 内容与 schema 声明，修正后可重新上传。

选择文件并点击“上传并检查”。支持 CSV、JSON、CPDataKit HDF5、NetCDF、Parquet，
Zarr 使用单独的目录上传入口。页面显示当前数据和规则，上传后可继续校验。

“高级设置 · 生成规则草案与预览字段映射”保留规则草案和字段映射功能。
确认草案中的单位与物理角色后，再点击“保存已确认的规则”。
高级映射只在转换操作中应用，校验和报告检查当前所选数据本身。
CSV 确认导入已经应用表格中明确声明的换算，不需要在高级映射中重复填写。

## 2. 检查数据，生成结果

选择已上传的数据，点击“校验数据”，查看本次文件、规则、错误和警告。
切换文件或规则后，之前的校验结论会标为历史结果；重新校验当前选择。

- **生成报告**：选择 HTML、Markdown 或 JSON，填写项目内保存路径，点击“生成报告”。
- **转换并保存**：选择目标格式和项目内路径；需要单位转换或字段改名时，先预览映射。
- **二维切片**：在高级查看中选择至少有两个维度的数值变量，一维曲线不使用此工具。

已有同名文件时，页面会指出输出路径。可以修改文件名另存；确实需要替换时，明确勾选
“我确认替换同名报告”或“我确认替换同名数据文件”后重新提交。
仅更换数据或规则，不会替你改写已有结果。

任务成功后可直接查看或下载结果。“结果等待保存”表示文件处理已经完成，目录记录仍待持久化。
在任务记录旁点击“查看中断输出的恢复信息（诊断）”，可查看待恢复目录、备份和未登记产物的证据。
恢复会重新核对项目、路径与内容摘要，再复制到项目内未占用的新位置。

## 3. 查看结果

“查看与下载结果”集中列出结果文件；任务记录单独显示“等待处理”“处理中”“已完成”
“未完成”和“已取消”状态。
历史记录按需加载。在转换结果旁点击“使用此结果继续处理”，会选中该结果保存时的快照
和原规则，并清除上一份数据的字段映射。随后可直接校验或生成报告，无需下载后重新上传。
重复点击复用同一份输入记录；报告文件不能用作数据输入。快照被修改、原规则不可用或结果
来自另一项目时会拒绝继续。后来覆盖同名输出，不会改变已经登记的旧快照。

新写出的 HDF5 1.0 保留数据列顺序，包括扩展列；显式指定 `fields=[...]` 时按请求顺序读取。
旧文件若没有记录创建顺序，默认仍按原有遍历顺序读取，不能自动恢复当时的输入列序。
下游生成不含字段名的特征数组前，应明确所需的字段及顺序。

HTML 报告可离线打开与打印。顶部显示文件、规则和校验概览，下方列出字段、数值统计、
问题与来源摘要。未提供的统计量标记为未提供，未声明的单位不会自动当作无量纲。
完整元数据保留在可展开的详细记录中。JSON 与 Markdown 报告仍沿用原有结构。

## 拉伸案例的第一步

真实案例资料位于源码仓库的 `examples/cpfe-tensile/`，普通 wheel 不附带这些案例文件。
在仓库根目录按 [KupferDigital 案例](../examples/cpfe-tensile/README.md) 生成 `experiments.h5` 和
`experiments.schema.json`，先上传规则，再上传数据。选择
`kupfer-tensile-measured-derived` 后运行校验，预期 `record = 483`。

这份数据含 H_08、H_16、H_18 三个样品，各 161 点。工程应变窗口为 0–0.008，
名义应力增量单位为 MPa。报告展示已有数据的结构和统计，不重新运行求解器，也不新增物理验证结论。
## 数值精度与外部依赖错误

普通“上传并检查”和 CSV“预览并确认字段”的解析合同不同：普通 CSV 仍按逗号、UTF-8
及已有缺失值约定推断，`001` 会作为整数、`NA` 会作为缺失值。标识符、日期原文或字面量
`NA` 需要保留时，使用 CSV 确认入口并选择“文字”，不要依赖自动推断。

普通 CSV/JSON 的整数与空值混合现在保留整数精度；不能安全表示的整数／小数混合、
数值溢出和非零数下溢会明确报错。单位不变或等价时保留原类型和值，实际换算也会检查精度。
格式写入器若无法保留缺失值与精度，会拒绝导出，不生成看似成功的错误结果。原文件不变。

HDF5 检查和导入拒绝外部链接、外部原始存储、虚拟数据集（VDS）及 SoftLink，
即使相关字段未被选择也一样。文件内 HardLink 可用。这个约束也覆盖 HDF5 2.0、DAMASK
和基于 HDF5 的 NetCDF。遇到此错误，需要用可信的原始工具另存为自包含文件，并保留原件；
工作台不会自动读取、复制或改写链接所指向的其他文件。
